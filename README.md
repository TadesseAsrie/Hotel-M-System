# Hotel Management System 

A modern, fully responsive Hotel Management System frontend built with **React.js**, **Tailwind CSS**, **React Router**, and **Recharts**. This application provides a complete dashboard for managing hotel operations including rooms, bookings, guests, staff, payments, reports, and more. It includes dummy data for demonstration and supports dark/light mode with smooth animations.

## ✨ Features

-  **Authentication UI** – Login, Forgot Password, Reset Password pages with validation.
-  **Dashboard** – Statistics cards, revenue/occupancy charts, recent activities.
-  **Room Management** – List, search, filter, sort, pagination, view details, edit, delete.
-  **Booking Management** – Manage reservations, search, filter, cancel, view details.
-  **Guest Management** – Guest profiles, booking history, search, pagination.
-  **Staff Management** – Add, edit, delete staff, filter by department.
-  **Payment Management** – Track payments, filter by status/method, view details.
-  **Reports** – Revenue, occupancy, booking reports with charts and export buttons.
-  **Calendar View** – Monthly/Weekly reservation calendar.
-  **Settings** – Hotel info, user preferences, notifications, security, theme.
-  **Profile Page** – Update personal info, change password, upload photo.
-  **Dark/Light Mode** – Toggle theme with persistent storage.
-  **Fully Responsive** – Mobile-first design with sidebar navigation.
-  **Modern UI** – Glassmorphism cards, animations, loading skeletons.

## 🛠️ Tech Stack

- **React 18** – Functional components & hooks
- **React Router v6** – Navigation & routing
- **Tailwind CSS** – Styling & responsive design
- **Framer Motion** – Animations & transitions
- **Recharts** – Charts & graphs
- **React Icons** – Icon library
- **Vite** – Build tool & dev server
